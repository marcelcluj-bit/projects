* **Repository:** [Agro-Smart-2026--Eco-Tourism](https://github.com/marcelcluj-bit/Agro-Smart-2026--Eco-Tourism)

* **Repository:** [Senior-Hub-2026--Residential-Care](https://github.com/marcelcluj-bit/Senior-Hub-2026--Residential-Care)
